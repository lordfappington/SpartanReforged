LEVEL00 supplies the first gameplay model, animation, entity, collision, navigation, terrain, and cutscene candidates. MODELS.BIN container segmentation, VIF streams, implicit strip topology, material indexing, AAB spatial lookup, and signed Q4.12 normalized UV mapping are established and implemented in a strict glTF reconstruction pipeline. The complete derived scene passes structural/exact accessor checks and Blender import with 46,336 polygons. Exact MTL sampler states, V4-8 semantics, and native visual conventions remain unresolved. Audio payload formats remain external/uninspected. Inner headers have been inspected only for GENERAL, FE_LANG, FE_TV, FE_MAIN, and LEVEL00.

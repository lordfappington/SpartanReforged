# Approved locked-state padlock

The JPEG in `source/` preserves the exact human-approved Reforged artwork. It
must not be recompressed or visually revised. The PNG in `runtime/` removes only
the connected exterior presentation field and the genuine opening inside the
U-shaped shackle. Lower enclosed dark artwork, including the keyhole, remains
opaque. Rebuild it deterministically with
`tools/reforged/frontend/build_approved_padlock.py`.

This is project-created production art approved for the public repository.

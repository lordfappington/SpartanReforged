# Cinzel

SpartanReforged uses Cinzel Regular and Bold for the Reforged main-menu navigation and supporting UI typography. Cinzel was designed by Natanael Gama, is inspired by first-century Roman inscriptions and classical proportions, and harmonises with the approved title without attempting to reproduce its custom lettering.

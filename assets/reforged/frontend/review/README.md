# Reforged Front-End Review Renders

This directory contains project-created SpartanReforged renders for remote art-direction and integration review. Original game screenshots, captures, extracted assets, and other redistributed game content must never be added here.

Current renders show the implemented Reforged UI, approved Reforged assets, and project-created procedural placeholders. Superseded review renders may be removed or archived after review.

`main-menu/current/menu-typography-material-diagnostic.png` is an enlarged, project-created inspection plate for the selected, unselected, and locked Cinzel material states. It contains no original-game imagery.

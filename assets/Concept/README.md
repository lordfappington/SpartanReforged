# Approved Concept Library

This directory contains HUMAN-APPROVED SpartanReforged concept artwork. Approved concepts are tracked production and art-direction references; they are not canonical original-game data.

Original extracted PS2 models, textures, renders, and other copyrighted reconstruction outputs must remain in ignored/private research locations such as `temp/` and must never be copied into this directory.

Codex must treat files containing `approved` in their production concept filename as locked visual references unless the user explicitly instructs that they be revised.

These concepts guide Reforged asset creation. Recovered original game assets remain the canonical source for structural and gameplay identity.

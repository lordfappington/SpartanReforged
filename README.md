# SpartanReforged

SpartanReforged is a research-stage preservation and engineering project investigating how *Spartan: Total Warrior* can eventually run on modern PCs while preserving original gameplay behaviour. The project is evaluating PlayStation 2 static recompilation, a native engine reimplementation, and other technically and legally viable remaster approaches.

No original game assets, disc images, or executables are distributed by this repository. Every user must supply data from their own legally owned copy. PCSX2 Nightly is the behavioural and rendering reference for research.

Untouched extracted assets belong under `assets/original` and must never be overwritten. Remastered or derived assets belong separately under `assets/remastered`. Disc contents and working extractions are deliberately excluded from Git.

Current status: **Milestone 0 — Environment Setup and Discovery**. Static recompilation is exploratory; no claim of game compatibility is made.
